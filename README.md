# Chill Thrive - AI Booking System

# Project Description
Chill Thrive is a modern web application for a recovery center (Ice Baths & Saunas). It features an automated AI chatbot for customer support and a real-time booking system.

# Features
* AI Assistant: Powered by Chatbase, capable of answering pricing and service questions.
* Live Booking: Users can book slots directly, and data is stored in the cloud.
* Real-time Database: Built on Supabase for instant data updates.

# Tech Stack
* Frontend: HTML, CSS, JavaScript
* Backend: Supabase (PostgreSQL)
* AI Agent: Chatbase
